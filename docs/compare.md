# Compared with other tools

Use this page to pick a tool by the job you want done and to see how `drive` compares with other Google Drive tools. The comparison itself lives on wirecat.dev, because it changes when the other tools change, not when `drive` is released.

Read the comparison: [`drive` compared with other tools](https://wirecat.dev/en/docs/drive/compare).

To let an agent edit a Google Doc a few lines at a time from a local Markdown file, while people keep working in the
Doc, use `drive mirrors`: it sends only the changed blocks and merges edits made in Google. See
[mirror local files with Google](mirrors.md).
