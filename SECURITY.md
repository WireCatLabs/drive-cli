# Security

Please report a security problem privately — never in a public issue or the support chat:

- by email: [hello@wirecat.dev](mailto:hello@wirecat.dev);
- or through [GitHub's private vulnerability reporting](https://github.com/WireCatLabs/drive-cli/security/advisories/new).

Say what you saw, how to repeat it, and the version (`drive --version`). Never send a Google token, an OAuth
client secret or the text of anyone's documents.

What the tool keeps on your computer and what stops an agent from writing:
[wirecat.dev/en/docs/security](https://wirecat.dev/en/docs/security), and the Google Drive details in
[docs/security.md](docs/security.md).
